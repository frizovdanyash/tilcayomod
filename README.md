# 🐾 Толстый Тилкайо

Android-игра про круглого пушистого тилкайо: прыгай от стены к стене вверх, пока снизу поднимается лава.

## Геймплей
- **Тап** — прыжок на противоположную стену (тап в воздухе буферизуется — прыгнешь сразу после приземления).
- На стенах шипы, по полю катаются пилы, снизу поднимается лава и ускоряется с высотой.
- Собирай монетки 🪙 и вкусняшки 🥕🍔🍰 — еда прямо в забеге откармливает бегуна.
- **Ферма**: покупай еду, откармливай тилкайо до 10 уровня, **размножай** новых (до 9 штук).
  Жирнее тилкайо → больше монет в забеге (и больше хитбокс, баланс!). Стадо приносит пассивный доход, даже когда игра закрыта (до 3 часов).

## Установка
Готовый APK: [`apk/tilcayo.apk`](apk/tilcayo.apk) — скачай на телефон и установи (разреши установку из неизвестных источников).

## Сборка
```
./gradlew assembleDebug
```
Нужны JDK 17+ и Android SDK (platform 35). Зависимостей нет — только Android SDK и Kotlin.
